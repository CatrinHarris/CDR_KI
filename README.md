# **UPTAKE Carbon Dioxide Removal Knowledge Inventory - DASHBOARD** [![Contributions welcome](https://img.shields.io/badge/Contributions-Welcome-brightgreen)](#submit-data-to-the-cdr-ki)



The Knowledge Inventory (KI) provides an overview of important data and parameters for CDR technologies. These include values from the literature, case studies, and techno-economic analysis, as well as input values used in Integrated Assessment Models (IAMs). While the KI may include results of certain analyses, including techno-economic modelling, it is not intended as a database of scenario results based on narratives of transformations of systems.

### **Visualizing and downloading data**

This GitHub repository provides a dashboard for the data hosted on the UPTAKE scenario explorer. Its functionality allows users to view, filter, and download the data. This GitHub repository is mirrored on the UPTAKE scenario explorer (link).

### **Submit data to the CDR KI**

The KI is a community resource and is open to continued improvement by the community. The KI’s data will be hosted on Zenodo, with versioned releases published regularly [![Data](https://img.shields.io/badge/Data-Zenodo-blue)] - link. This GitHub repository is the place where new data can be submitted to the KI.

Step 1: Fork the repo. 

Step 2: Edit the Excel file with your data entries (see **Adding data entries**) and commit your changes. 

Step 3: Submit a pull request for the data to be committed to the original repo. 

Step 4: This repo's owners will review the changes and merge the pull request. 


### **Adding data entries** 
Data should be entered following the protocol, including the completion of all mandatory fields and the use predefined options wherever possible to maintain consistency, comparability, and quality control as the database expands. Full details of how to fill in the KI can be found on the Excel cover page. The data template for the KI has a standardised structure as follows:
1. One worksheet per carbon dioxide removal Technology
2. A predefined list of parameters that can be included in the KI. These are presented in columns B to H
3. A set of data fields to be completed, shown in columns I to R. Every single cell in columns I to R should be filled in; do not leave any fields blank.
4. Everything above the shaded row should be considered a template and should not be edited
5. For some technologies, the KI can accommodate different variants of each technology. These variants are listed in tables at the bottom of the template. Only these variants should be used in the Sub-Component and Variation columns as indicated in the template. If you are providing data for a sub-technology, please make that clear in the metadata column.

**Important:** Please create a new row below the shaded row by copying and pasting an existing template row. Complete the new row (columns I to R) using the relevant information from your source. Enter values using the specified units for each variable. Please follow the same format, structure, naming, and units as in the template. See examples in the data already provided.
